Security

Controls in place · Version 2026-10-24

Access

  • Professional accounts are verified by AIRA Adaptive before they can run assessments.
  • AI assistants connect through OAuth 2.1 with PKCE; AIRA Adaptive never receives or stores your assistant credentials, and stores its own connection tokens only as cryptographic hashes.
  • Each organization can access only its own assessments, enforced in the database.
  • Server credentials are never sent to browsers or AI assistants. Sign-in and authorization endpoints are rate-limited.

Data minimization

  • Only structured clinical fields are accepted; names, contact details, ID numbers, dates and case aliases are never requested.
  • History is shown to the assistant with the year only.
  • The connector does not read the assistant's memory, chat history or files.
  • Inputs are validated on the server before any assessment is used.

Audit

Each completed or failed assessment records the consents confirmed, the professional who confirmed them, the time, the version of the privacy notice and the assistant used (Claude or ChatGPT). Connections are logged with the assistant used. Application logs contain technical codes only, never clinical data or tokens.

Infrastructure

Data are hosted by Supabase in the United States (AWS us-east-1), encrypted in transit. See the Privacy Policy for providers, retention and your rights.

Reporting a vulnerability
